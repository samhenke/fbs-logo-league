# Logo League

A college football logo quiz covering all 138 FBS programs in the 2026 season.

- Filter by conference and choose a 10-logo, 20-logo, or full-field round.
- Play multiple choice or type a school name. Full school names, abbreviations, and alternate names are accepted.
- Selecting a suggested school submits the guess immediately.
- Challenge a friend: finish a challenge round and copy the link. Your friend gets the same teams, order, answer style, and answer options, with your score to beat.
- Lifetime progress is saved in your browser.

## Hosting

This is a static website. Publish the root folder through GitHub Pages from the main branch. No build step is required.
