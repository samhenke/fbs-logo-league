# Logo League

A college football quiz covering all 138 FBS programs in the 2026 season.

- Filter by conference and choose a 10-question, 20-question, or full-field round.
- Play multiple choice or type a school name. Full school names, abbreviations, and alternate names are accepted.
- Selecting a suggested school submits the guess immediately.
- School → nickname mode shows a school name and asks you to type its team nickname (for example, Kansas State → Wildcats). It also supports friend challenges.
- Challenge a friend: finish a challenge round and copy the link. Your friend gets the same teams, order, answer style, and answer options, with your score to beat.
- Helmet → school mode shows one representative helmet photograph for each of the 138 schools. Type a school name or select a suggestion to submit a guess. Conference filters, missed-answer practice, and friend challenges work in this mode.
- School → mascot mode asks for the mascot’s character name (Kansas State → Willie the Wildcat). After five matching letters, clickable suggestions appear; selecting one submits the guess. Common aliases and any listed mascot are accepted. Schools without a mascot accept “No official mascot” or “None.” Conference filters, practice, and friend challenges work in this mode. Mascot mastery is tracked separately.
- Lifetime progress is saved in your browser.

## Hosting

This is a static website. Publish the root folder through GitHub Pages from the main branch. No build step is required.

## Credits

Team logos and team data: ESPN. 2026 FBS membership: CollegeFootballData. Helmet photographs: [Helmet History](https://www.helmethistory.com/). Original image links and design notes are recorded in `helmet-sources.json`. Each school has one representative design; teams may also wear other helmets.

Mascot references, checked exceptions, and naming notes are in `mascot-sources.json`. The dataset includes named costumed characters, live mascots, and widely recognized symbolic mascots. The Stanford Tree is unofficial; retired mascots are excluded.

Team marks belong to their respective institutions. This is an independent fan quiz.
